考试辅助 · 模型设置

所有配置只保存在本机 chrome.storage.local，直接由你的浏览器发往你填的接口，不经过任何中转服务器。

接口

选择后会自动填好 Base URL 与模型名，密钥仍需自己填。
填到 /v1 即可，插件自动补 /chat/completions；也可直接填完整地址。
本地 Ollama 之类的免密接口可以留空。
本地 OCR 用 Tesseract 在浏览器内识别，完全不联网；印刷体准确，手写/复杂排版略弱。
docx / 扫描版 PDF / 图片里的多道题目与表格会自动识别并逐题切分入库（有视觉模型按“图片题识别方式”优先使用视觉，否则用本地 OCR），关掉则只取正文文字。
记录写到浏览器下载目录的 exa-答题记录-日期.jsonl，一行一条，方便事后核对。

知识库

上传题库、讲义、课程笔记。插件会把文件切成「题目 → 答案」「术语 → 定义」条目，在本地建索引；解题时先查知识库，命中就不调模型，并在面板里标注来源是知识库还是AI。
点击选择文件 或把文件拖到这里（支持多选）
txt / md / csv / tsv / json / pdf / docx / xlsx / html / png / jpg / webp

并发越高越快，但更容易触发接口限流。

    


    

      
      

        
复核模式（解得慢一点，正确率更高）

        
第一遍作答后，再让模型独立推演一次；两次不一致时采用复核结果并标注。

      

    


    

      
      

        
解完自动填涂

        
关闭时只显示答案，由你在面板里逐题确认后点「填入」。

      

    


    

      
      

        
AI 语义扩展检索（推荐）

        
题库里有相关内容、但题干措辞对不上时，让模型把题干改写成几种同义问法再检索一次，明显提高命中率。仅在被判定"相关但不够精确"时触发，不会每题都多花 token。

      

    


    

      
      

        
只在匹配的网站启用（每行一个，支持 * 通配符）

        
留空表示所有网站都启用。建议只填考试站点，避免在配置页、网关上无谓地跑。例：exam.company.com、*.edu.cn。

      

    


    

      
      

        
显示答案来源标记

        
填入答案后，题目上方会短暂显示「来自知识库 · 可信度 99%」。不想看到就取消勾选。

      

    


    

      
      

        
标记停留时长（毫秒）

        
默认 1500（1.5 秒）。上面的开关关掉时这一项不生效。

      

    


    

      
      

        
只用知识库（严格模式）

        
只采用题库里精确命中的答案；没收录的题明确标注「知识库未收录」，不调用模型猜测。

      

    


    

      
      

        
跟随模式（推荐）

        
你翻到新的一题，它自动识别、作答并填上；不会自己翻页，节奏完全由你控制。

      

    


    

      
      

        
隐式模式

        
不显示悬浮面板，页面上不挂任何 UI；需要时按 Alt+Shift+Q 才唤出。

      

    


    

      
      

        
自动连做时自动翻页

        
只在点「自动连做」后生效；默认关闭，避免它自己往下跑。

      

    


    

      
      

        
不覆盖页面上已有作答

        
填涂前先看这道题是不是已经答过；答过就跳过，避免把你自己改过的答案冲掉。

      

    


    

      
      

        
复用答案缓存（省 token）

        
同一道题第二次出现时直接用上次的答案，标注「缓存答案」；知识库优先于缓存，缓存优先于模型。
