期末复习题库（节选）

1. 一个物体在水平面上做匀速直线运动，则它受到的合外力（ ）。
A. 方向与速度相同
B. 方向与速度相反
C. 等于零
D. 大小恒定但方向不断改变
答案：C
解析：匀速直线运动的加速度 a = 0，由牛顿第二定律 ΣF = ma 得合外力为零。合力方向与速度相同或相反都会改变速度大小，不合题意。

2. 下列属于操作系统的是（ ）。
A. Linux
B. MySQL
C. Windows Server
D. Nginx
答案：AC
解析：操作系统负责管理硬件资源与进程调度。MySQL 是数据库管理系统，Nginx 是 Web 服务器与反向代理，二者都运行在操作系统之上。

3. TCP 协议在网络层工作，提供无连接的数据报服务。（ ）
A. 对
B. 错
答案：错
解析：TCP 工作在传输层，面向连接、提供可靠字节流；无连接的数据报服务是 UDP 与 IP 的特征。

4. 在关系数据库中，用于唯一标识一条记录的属性或属性组称为（ ）。
A. 外键
B. 主键
C. 索引
D. 视图
答案：B
解析：主键（Primary Key）唯一且非空地标识元组。外键用于参照完整性，索引用于加速检索，视图是虚表。

5. 缓存击穿与缓存穿透的区别是什么？
答案：缓存穿透是查询一个数据库里也不存在的键，请求每次都打到数据库，常用布隆过滤器或空值缓存解决；缓存击穿是某个热点键过期瞬间大量并发直接打到数据库，常用互斥锁重建或逻辑过期解决；缓存雪崩则是大量键同时失效，用过期时间打散与多级缓存应对。
解析：三者常被混淆，答题时按"失效对象—触发条件—常见解法"三段式展开即可。

6. 简述进程与线程的主要区别。
答案：1. 资源：进程是资源分配的基本单位，独占地址空间；线程是 CPU 调度的基本单位，共享所属进程的地址空间。2. 开销：进程创建/切换需切换页表与地址空间，开销大；线程切换只需保存少量寄存器与栈。3. 通信：进程间需借助管道、共享内存、消息队列等 IPC 机制；线程可直接读写共享变量，但需要同步。4. 健壮性：一个进程崩溃不影响其他进程；一个线程崩溃可能拖垮整个进程。
解析：答出"资源分配 vs 调度单位""开销""通信方式""隔离性"四个得分点即可。
